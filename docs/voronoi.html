通常の Voronoi 図

各入力点に最も近い領域を返します。図全体は VoronoiDiagram(sites) で O(N log N) 時間、O(N) メモリで構築します。全点対の半平面交差を N 回行う実装ではなく、Delaunay 三角形分割の隣接関係を使います。各サイトは入力配列の添字で指定します。

#include "geometry/voronoi.hpp"
namespace cg=cp_geometry;
std::vector<cg::Point> sites{{-1,0},{1,0},{0,2}};
cg::VoronoiDiagram diagram(sites);
auto cells=diagram.cells({-5,-5},{5,5});
auto cell=diagram.cell(0,{-5,-5},{5,5});
auto area=cg::polygon_area(cell);
API意味計算量
sites()元の入力配列への const 参照O(1)
triangulation()重複除去した点・三角形・Delaunay 辺O(1)
site_owner(i)同一座標の点で最小の入力添字O(1)
vertices()有限頂点。各要素の point が座標、site が接する元サイト1つO(1)
edges()有限線分・半直線・直線の配列O(1)

voronoi_diagram(sites)、voronoi_cells(sites,lower,upper)、voronoi_cell(sites,i,lower,upper) もあります。これらの自由関数は呼ぶたびに図を構築するので、繰り返しの問い合わせにはクラスを保持してください。

非有界な辺

VoronoiEdge は origin + direction * t のパラメータ表示です。first_site と second_site は元の入力添字です。

kindt の範囲
VoronoiEdgeKind::segment[0,1]
VoronoiEdgeKind::ray[0,+∞)
VoronoiEdgeKind::line(-∞,+∞)

edge.clip(lower,upper) は矩形との共通部分を optional<pair<Point,Point>> で返します。非交差は nullopt、接点だけなら同じ点を2個返します。edge.segment_intersections(a,b) は線分との交点を a→b の順で返し、重なる場合は重複部分の端点を返します。

共線点だけの入力では、隣り合う点の垂直二等分線を直線として返します。点が1個なら辺はなく、セルは全平面です。矩形に切ったときには矩形全体になります。0点の図は空です。

重複点・共円

同一座標の点は完全一致で判定し、小さい入力添字のみ正面積のセルを所有します。重複した非所有者の cell() は空です。重複点を含む全セルの面積を合計しても二重計上しません。所有者は site_owner()、Delaunay 側の対応は original_to_site と representative で確認できます。

4点以上が同じ円上にある場合、Delaunay 三角形分割は対角線を選びます。その双対にできる同じ中心の頂点をまとめ、長さ0の辺を削除します。有限座標の計算と同一視には浮動小数点の誤差があり、非常に近い別頂点を eps=1e-12 でまとめる場合があります。セル生成には冗長な Delaunay 隣接制約が含まれる場合がありますが、領域は変わりません。

最大空円

auto box_answer=cg::largest_empty_circle_in_box(diagram,{-5,-5},{5,5});
std::vector<cg::Point> polygon{{0,0},{6,0},{6,2},{2,2},{2,6},{0,6}};
auto polygon_answer=cg::largest_empty_circle_in_polygon(diagram,polygon);
if(polygon_answer) {
    auto center=polygon_answer->center;
    auto radius_squared=polygon_answer->squared_radius;
}

点集合を円の開内部に含まない最大半径の円を求めます。指定する矩形・多角形に制限されるのは中心だけです。 円板全体が領域内に入る「最大内接円」とは異なります。境界上の入力点は許します。入力サイトが0個なら半径の有限な上限がないため nullopt、単純多角形が3頂点未満でも nullopt を返します。

矩形版は全セルの頂点を調べて O(N log N)。単純多角形版は、内部の Voronoi 頂点、Voronoi 辺と多角形辺の交点、多角形頂点を調べ、M 頂点の領域に対して O(NM + N log N) です。凹多角形・CW/CCW の両方に対応します。自己交差や穴のある多角形は対象外です。

精度と利用環境

Delaunay の向き・円内判定は専用の浮動小数点展開で符号を補いますが、Voronoi の中心・交点・セル切断は long double の近似構成です。ほぼ共線な点では中心が非常に遠くなり、誤差が増幅されます。有限座標と中間積が表現できること、点と矩形辺の長さが eps より十分大きいことを前提とします。共通の巨大な平行移動には各セルのローカル座標で対処します。全ての極端なスケールを厳密処理するAPIではありません。

C++17、外部パッケージ不要。普段の my_template.hpp と併用でき、グローバルなマクロは追加しません。Delaunay の二進・最近接丸めの条件、GCC 以外の fast-math 制約は Delaunay の説明を参照してください。

検証

Delaunay は整数の空円・向き・辺の交差・Euler 個数を独立検証します。Voronoi セルは全点対の逐次多角形切断と比較し、全セルの面積和と各辺上での最近点条件を確認します。共線・共円・重複・領域外サイト・平行移動、小さな矩形、凹多角形と最大空円も検証します。Panda Preserve の公式サンプルも回帰に含めます。外部ジャッジでの AC を表示するものではありません。

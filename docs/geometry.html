Point の構築

Point(x, y)、Point{x, y} のどちらでも構築できます。Point() は (0,0) です。C++17 の vector<Point>::emplace_back(x,y) と constexpr 構築にも対応します。

入力テンプレートとの併用

IN という幾何の定数は入力関数 IN(...) と競合するため廃止しました。内外判定は Location::outside（0）、Location::boundary（1）、Location::inside（2）です。コード中の旧 IN/ON/OUT との比較を書き換えてください。これにより using namespace cp_geometry; と普段の INT(x) を併用できます。

新しい幾何ヘッダは namespace やマクロをグローバルに追加しません。INT/IN/OUT、min/max、all/rep 等はヘッダ内部で一時的に退避し、読込後に元通り復元します。実際の my_template.hpp を先・後に読み込む2通りでテストしています。namespace cg=cp_geometry; と必要な型を修飾して使うと、他のライブラリの型とも区別できます。任意の識別子を置換するマクロや #define int ... に対応する保証ではありません。

凸多角形のクエリ

任意の点集合は ConvexPolygon(points) に渡します。重複と共線中間点を除く凸包の前処理は O(N log N) です。すでに厳密な単純凸包がある場合は ConvexPolygon::from_convex_hull(hull) で O(N) で構築できます（CW/CCW対応、閉じ点の重複なし）。辺方向は凸包上で巡回的に整列しているため、再ソートせずにインデックスを作ります。

API意味計算量
contains(point)内外判定、境界を区別O(log H)
support(direction)内積を最大化する頂点の添字O(log H)
line_intersections(line)直線に沿った順の境界交点0〜2個。辺に重なると両端O(log H)
convex_diameter2(hull)最遠点対距離の二乗。厳密CCW凸包O(H)
convex_cut(polygon,line)有向直線の左側に残す凸切断O(H)

空集合・1点・線分への退化も扱います。空の support は例外、方向0では任意の頂点です。一般の単純多角形には O(N) の contains(polygon,point) を使います。

半平面交差: ax + by <= c

#include "geometry/halfplane.hpp"
namespace cg=cp_geometry;
std::vector<cg::HalfPlane> constraints{
    {-1,0,0}, // x >= 0
    {0,-1,0}, // y >= 0
    {1,0,4},  // x <= 4
    {0,1,3}   // y <= 3
};
auto region=cg::half_plane_intersection(constraints);
// region.kind == cg::RegionKind::POLYGON
auto area=cg::polygon_area(region.polygon); // 12
auto clipped=cg::half_plane_intersection(constraints, cg::Point{-10,-10}, cg::Point{10,10});

境界を含む閉不等式です。a=b=0,c>=0 は制約なし、c<0 は矛盾として扱います。法線を正規化するため正の係数倍で意味は変わりません。従来の std::vector<Line> 入力では有向直線の左側を残します。空配列を直接 {} で渡すと型が曖昧になるため、空の場合も vector の型を明示してください。

RegionKind結果
EMPTY実行可能点なし
UNBOUNDED非有界。直線・半直線を含む。witness は実行可能点
POLYGON有界の正面積多角形。polygon はCCW頂点列、witness も返す
DEGENERATE有界の点・線分。witness のみ返す。線分の端点は返さない

一般版は乱択増分の実行可能性判定と偏角ソート・deque を使い、期待 O(N log N)、最悪 O(N²) です。再現可能な固定シードなので最悪計算量保証ではありません。矩形付きの版は矩形も制約に含めた O(N log N) のアルゴリズムで、空・点・線分なら空配列です。勝手に大きい定数で無限領域を近似する仕様ではありません。

精度と制限

Real は long double、eps=1e-12 は絶対誤差です。点距離、直線の単位方向、外積・面積で尺度の意味が異なるため、極小図形・ほぼ共線な点・ほぼ平行な直線を厳密に区別する整数幾何ではありません。法線の角度差が eps 以下の半平面は平行として扱います。ほぼ平行な制約に対する大きな領域では結果の誤差が増幅されます。

座標・内積・外積・中間結果が Real に収まる有限値を想定します。巨大な平行移動は面積の相対座標化で軽減しましたが、境界上の点に単位方向を足すことも表現できないほど遠い半平面では座標の平行移動・スケーリングが必要です。ソートに epsilon 比較は使いません。

検証

内外判定・support・直線交点は全辺・全頂点の素朴解、半平面交差は逐次凸切断と比較します。係数の正の拡大縮小、平行・逆向き・角度0をまたぐ方向、退化、巨大な共通平行移動、空集合も検証します。外部ジャッジACを示すものではありません。

Voronoi / Delaunay / Power Diagram

点集合を最も近いサイトの領域に分ける通常の Voronoi 図と、距離の二乗から重みを引く Power Diagram を追加しました。通常版は Delaunay の双対によって全体を O(N log N) で構築し、非有界な辺と矩形内のセルを取得できます。

  • geometry/delaunay.hpp
  • geometry/voronoi.hpp
  • geometry/power_diagram.hpp

Voronoi 版では指定した矩形・単純多角形に中心を置く最大空円も求められます。Power 版は円を重み付きサイトへ変換でき、Universal Cup の Galaxy War 型の領土面積を扱えます。重み付きの全図はセルを独立に計算する O(N² log N) 版で、通常の図と計算量が異なります。

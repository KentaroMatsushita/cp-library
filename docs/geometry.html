凸多角形の O(log N) クエリ

ConvexPolygon(points) は点集合から凸包を作り、辺の偏角順インデックスを準備します。前処理は O(N log N)、保持する頂点数を H とするとメモリは O(H) です。返される凸包は反時計回りで、連続する3頂点は一直線上にありません。

API戻り値計算量
contains(p)OUT=0 / ON=1 / IN=2O(log H)
support(direction)内積が最大になる頂点の添字O(log H)
line_intersections(line)直線に沿った順に境界との交点0〜2個O(log H)
vertices()凸包頂点配列への const 参照O(1)

内外判定は先頭頂点からの扇形を二分探索し、最後に三角形の外側の辺で判定します。support は方向と直交する辺の偏角を二分探索します。直線交点は法線方向の最大・最小頂点を求め、その間の2本の単調な鎖をそれぞれ二分探索します。クエリ内で全頂点を走査したり、凸包を再構築したりしません。

直線が辺に重なるとその辺の両端、頂点で接すると1点です。空集合・1点・線分に退化した凸包にも対応します。空集合での support は例外、方向ゼロは任意の頂点を返します。Line は異なる2点が必要です。

半平面交差

有向直線 a→b の左側（境界を含む）を残します。不等式 Ax+By≥C は、直線上の点 a と方向 (B,-A) から作れます。例えば x≥2 は a=(2,0), b=(2,-1) です。

std::vector<Line> constraints{
    Line({0,0},{1,0}),  // y >= 0
    Line({0,0},{0,-1})  // x >= 0
};
auto region = half_plane_intersection(constraints);
// region.kind == RegionKind::UNBOUNDED

auto polygon = half_plane_intersection(constraints, Point{-10,-10}, Point{10,10});
// [0,10] × [0,10] の頂点列
kind意味結果
EMPTY実行可能点なしpolygon は空
UNBOUNDED非有界（直線や半直線も含む）witness に実行可能点
POLYGON有界で正の面積を持つpolygon に反時計回り頂点列、witness に実行可能点
DEGENERATE有界な1点または線分witness のみ。線分の両端は返さない

一般版は、ランダム順の制約に対して原点に最も近い実行可能点を更新します。違反した制約の境界上で、以前の制約を1次元の区間に変換します。実行可能なら辺方向の最大角度差から非有界性を判定し、有界の場合は偏角ソートと deque で境界を作ります。全体は期待 O(N log N)、最悪 O(N²)。乱数シードは再現可能な固定値なので、入力に対する最悪計算量保証ではありません。

矩形付きの版は矩形も制約に加え、ソートと deque のみを使うため O(N log N) です。交差が空・点・線分の場合はいずれも空の頂点列を返します。矩形外の領域は切り捨てられます。無限領域を大きな定数で置き換える仕様ではありません。

精度と退化の扱い

座標・内積・外積に long double を使い、ゼロ判定は絶対誤差 1e-12 です。辞書順・偏角ソートには epsilon 比較を使いません（推移律が壊れるため）。ほぼ重なる点や直線はゼロ判定で同一視される場合があります。整数の厳密判定、極端なスケール、NaN/無限大の入力はこの実装の保証対象外です。交点が有限でもほぼ平行な直線では誤差が増幅されます。

検証

固定シードのランダム点集合について、凸内外判定は一般多角形 O(N) 判定、support は全頂点走査、直線交点は全辺走査、直径は全点対と比較します。半平面交差は逐次凸切断の面積と比較し、実行可能点・返却頂点が各制約を満たすことも調べます。加えて辺との重なり、接点、平行・逆向き・重複した半平面、点・線分への退化、空集合・非有界領域を確認します。外部ジャッジでの AC を示すものではありません。
